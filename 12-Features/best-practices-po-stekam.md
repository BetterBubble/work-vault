# Best practices по стекам разработчиков

**Статус: выложено на вики 3 августа 2026, ждёт ревью команд.**

Задача Дмитрия Лебедева с дейли 31.07: провести исследование ресурсов, где публикуются best
practices, по стеку каждого профиля разработчика, выложить на вики и отдать командам на ревью.
Выросла из жалобы Егора Кожанова (фронтенд): агентные профили пишут код «в стиле 2025», хотя авторы
фреймворков уже рекомендуют иначе, и объяснять это агенту в каждой задаче приходится руками.

Постановка дословно — [[brief-bestpractices-2026-07-31]], план — [[plan-bestpractices-2026-07-31]].

## Что сделано

**Опубликовано двенадцать страниц** в пространстве `IVAPROJECT`, корневая —
https://wiki.iva.ru/pages/viewpage.action?pageId=215287770 («Best practices по стекам», дочерняя к
«Tacticum agentic dev platform», рядом с «Набором профилей»). Под ней одиннадцать страниц: десять по
стекам и одна сквозная по агентному слою.

**Резали по стекам, а не по профилям.** Профилей разработчиков двадцать, но на один стек приходится
по 2–3 профиля (роль + brownfield + development-base), поэтому исследований девять, а не двадцать:
Angular · Firebird web · React Native · Go · Java · KMP · Swift (язык и сборка отдельно) · C++/Qt ·
Python+Next.js. Плюс десятая, сквозная — агентный слой, общий для всех.

**Каждая страница устроена одинаково:** строка-вердикт «в профиле → актуальная версия →
поддерживается ли», таблица источников (что берём · как часто обновляется · дата сверки), «что
изменилось за последний год», «что переписать в профиле прямо сейчас» (по 6 конкретных правок) и
пустая графа владельца стека, которую заполняет команда.

## Что вскрылось — важнее исходной задачи

**Пять стеков сидят на версиях без исправлений безопасности.** RN 0.77 вне поддержки с лета 2025
(текущая 0.86, и апгрейд возможен только через промежуточный 0.81 — Old Architecture физически
удалена с 0.84); Qt 5.15 без апстрим-багфиксов с 26.05.2025; ESLint 9 EOL 06.08.2026; Node 20 EOL
30.04.2026; CocoaPods trunk становится read-only 02.12.2026, а UCIM на нём собирается.

**Семь вендоров из восьми уже отдают правила машиночитаемо**, и это меняет саму задачу: часть
содержимого профилей надо не обновлять, а удалить и заменить подключением. Свод правил в смысле
«как писать код» дают четверо — Angular (`best-practices.md` + скиллы + MCP), Qt (14 скиллов),
Quarkus (скилл внутри каждого расширения), частично Go (`gopls mcp`). Остальные отдают документацию,
что не то же самое.

**Версии Swift и Xcode в профилях не зафиксированы вообще**, а косвенные пины в скиллах означают
Swift 5-семантику: у One — `swiftLanguageMode(.v5)`, у UCIM — `SWIFT_VERSION 5.2`.

## Как публиковали

Личным каналом записи Президента в helm: таблица `external_credential`, запись
`taktikum_a.shulga@iva.ru` / `confluence`, заведённая его согласием 30.07. Access-токены живут час,
но refresh рабочий — продление на месте. Права на `IVAPROJECT` подтверждены делом: чтение, правка,
создание. Значение токена в сессию не выводилось ни разу.

**`CONFL_TKN_SOL` (токен Солонко, которым ходит `wiki_sync_manuals.py`) у нас отсутствует** — ни в
репозиториях, ни в `.env` на helm. Рецепт публикации для других лидов — [[kanal-zapisi-wiki-2026-08-03]].

Скрипт синка профилей не трогали: он переписывает родительскую таблицу по всем профилям целиком и
для отдельной страницы не годится. Конвертер markdown → Confluence storage написан свой (на проде
нет библиотеки, ставить пакеты ради конвертации текста незачем).

## Проверка

Два критика с оппонированием.

**По фактам** — вердикт «можно после правок», девять ошибок, все исправлены: критичная (Next.js 16.3
назван стабильным, хотя он Preview — стабильная 16.2), три существенных (выдуманная дата Maven rc-5,
несуществующая на дату сверки Go 1.27 как минимум grpc-go, React 19.2.8 против реальной 19.2.7 при
том, что соседняя заметка называла верную). Все громкие утверждения сверены с первоисточниками
дословно и подтвердились.

**По пользе** — вердикт «решает не ту задачу, что ставил Егор»: каталог ссылок не даёт способа
увидеть или починить «пишет по-старому». По его разбору добавлены: раздел «что переписать прямо
сейчас» в каждую страницу, графа владельца, вынос находок по безопасности наверх корневой,
дисклеймер «это наша компиляция, а не позиция вендора», сквозная страница про агентный слой.

## Развилка «один профиль vs режим=лейн» — СНЯТА (решение президента)
Действуем по докам Солонко: **режим = процесс-лейн** (ADR-0056/57/59). «Один профиль» реализуется как **роль-композиция лейнов** (пользователь видит один профиль; режимы-лейны внутри; входной гейт выбирает лейн). Не переоткрывать.

## Скоуп (по пакету)
Таксономия ~5 режимов вместо «всегда полный конвейер»:
- **Багфикс** — ✅ есть (`tacticum-bugfix-base`/`/fix-bug`).
- **Лайт-доработка** — новый (refactoring-S / feature-S), **из kmp-прототипа**.
- **Полный** — ✅ есть.
- **Research** — новый лейн `tacticum-research-base` / `/start-research` (report + черновик ADR, без кода).
- **Рефакторинг** — refactoring-S в лайте; кампании — по спросу.
Два механизма поверх: (1) **входной гейт** — автоклассификация по тексту ТЗ, классифицировать→предложить→**подтвердить**, никогда молча не переключает; выход «ТЗ недостаточно — до 3 вопросов»; (2) **пересмотр режима по фактам** — тупик → смена флоу + `handoff.md` (лечит «агент сдался»).

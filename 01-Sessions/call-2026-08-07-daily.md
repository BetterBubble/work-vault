## 8. Переезд на GitLab — состояние и план

| Что | Где сейчас |
|---|---|
| `tacticum-re` | **переехал**, деплоится из GitLab (сделал Глеб) |
| `tacticum-df` | зеркало в GitLab есть, **не переехал**, пушит в GitHub |
| остальное (~10 реп: Project Hub, LLM Gateway, платформа) | не переезжали |

Порядок: сначала то, что активно дорабатывают, остальное позже. При переезде разработчику надо
**поменять `origin` с GitHub на GitLab**, CI/CD отрабатывает сама на pull request; `main`
дополнительно закрывается. Занимается Воронцов.

**Зачем:** нормальный деплой, лучше мониторинг и **отдельный контур** — выкатывать сначала на
stage, гонять там тесты, и только потом в прод. Обсуждали купить железку вместо VPS; решили
спросить Воронцова как ответственного за инфраструктуру.

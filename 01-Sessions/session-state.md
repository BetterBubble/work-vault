## Ключевые факты

1. **Три механизма за сутки рапортовали успех без успеха:** бот говорил Острякову «всё работает»
   при мёртвом канале · сервер отвечает `200` на неудачный резолв · скрипт #816 считал успехом
   строку `"Unknown tool"`. Это класс, а не совпадение.
2. **ГОСТ-задача переопределена:** генерация с нуля не нужна («всё делаем по эталонам»), скоуп —
   только программная документация, контур ИВА согласован. Заказчик сам оценил выгоду в 10–20%
   и задал критерий **порогом усилий**: «если тяжело — не окупается». Настоящая боль — 180 страниц
   со 150 скринами на каждом релизе.
3. **Закрытый контур возможен полностью** — у `triva` есть function calling, зрение с OCR и
   стриминг (проверено ~25 живыми вызовами). Прежнее «локального зрения нет» — неверно.
4. **Общий корень бэклога:** `pin-authoring/SKILL.md` в 18 профилях, 13 разных хешей; фикс #811
   лежит в одной копии. Девять из двадцати живых пунктов — проявления этого.
5. **Норма Президента 06.08:** мерж только по выполненной приёмке —
   [[2026-08-06-merzh-tolko-po-vypolnennoy-priyomke]].
6. **Две мои ошибки основания:** апрувил #750 по `origin/main`, не проверив прод-каталог (там жила
   строка `assets`, поймал verifier); запретил менять вариант #816, приняв авторство из поля
   `owner`, которое в нашем `taiga-mcp` одинаково у всех задач. Обе записаны в глоссарий как ловушки.

- **`iva-write`: личные ключи или служебная учётная запись.** Плюс найден четвёртый вариант: прав

- **QA** — пересекается с работой Ивана Монахова, наше направление на паузе.

## Что решено и НЕ переигрывать

- **Семь скрытых токенов везём как есть** — вычистить нечем, фильтр сработает с первой пересборки.
- **Автоподтягивание из Figma — в тех-долге**: нет выгрузок, нет доступа, нет владельца переданных
  работ.
- **Матч токенов по именам, а не по идентификаторам** — не переписываем: смена модели сборщика.
- **Про выбор профиля людям не пишем** — команда обновится сама.
- Отбракованная ветка `feat/kmp-token-migration` в remote не запушена, подобрать нельзя.

## Ключевые операционные факты

- **Прод-выкатка профилей:** дамп → снимок пинов файлом → деплой сервиса → сид → перепинивание
  **канареечно, сначала одна установка**. Рунбук отката в `docs/runbooks/`.
  **Пересборка сервиса — 58 секунд**; реестра образов нет, откат = пересборка (ADR-0043 Proposed).
- **Установок в проде 22** (было 13 в снимке 25.07). Недельный снимок как источник правды не годится.
- **Сид аддитивен, пин сам не катится** — до перепинивания у людей не меняется ничего.
- **`main` живёт с 35 красными e2e-тестами установки** — чужой дрейф эталонов у пятнадцати профилей.
  «Тесты зелёные» читается только как дельта.
- **Эталона установки для `iva-kmp-brownfield` не существует** — профиль со всеми живыми
  установками по содержимому не сверяется.
- **Почерк всех крупных находок дня — тихая потеря при зелёной сборке:** стирание словаря связей,
  подмена Compose-версий веб-версиями, потеря значения тёмной темы, мусор в теле навыка. Ни одна не
  падала. Поэтому чинили и проверки: паритет по телам вместо имён, сверка эталонов по хешам.
- Репозиторий переехал: `TacticumApps/tacticum-dev` → **`TacticumApps/dev`**, локальный remote
  обновить.
- Серверы — только чтение вне объявленного окна.

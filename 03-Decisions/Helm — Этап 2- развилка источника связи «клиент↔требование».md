# Helm — Этап 2: развилка источника связи «клиент↔требование»

**Статус: ОТКРЫТО** (обсудили 2026-07-08, отложили). Нужно для Этапа 2 (клиенты/пилоты) — свод по клиентам + вид «требования по пилоту». Часть B кода (модель `RequirementClient` + дэш) можно строить параллельно; упор — в источник данных связи. Связано: [[Helm — Conformance v2- 3-этапный план (многомерная матрица требований 1.0+1.5)]], [[Helm — сущностная ER-модель (30 сущностей)]], [[Helm — провенанс сущностей (откуда и насколько верим)]].

## Факты по серверу (проверено)
- [context] Связи требование↔клиент в модели НЕТ: `client`=0 строк, `need`=0, `requirement.need_id` не проставлен, у requirement нет клиентского поля.
- [context] Требования 1.5 кеются ХЕШЕМ (`external_ref`=`1.5-cbd5f240…`), не номером строки вики → join «Заказчик»→requirement только по названию (fuzzy).
- [context] Пилоты как клиенты ЕСТЬ в данных (SD/sales, коды): Транснефть=TRN · МВД=MVD · ВЭБ.РФ=VEB · Еврохим=ECH · **Метро=HT-MC (Московский метрополитен — синоним закрыт)** · Фортеинвест. ЦБ/Мосбиржа — в этих срезах не всплыли.
- [context] Воронка Signal→Need→Requirement НЕ материализована (по FK не пройти).

## Развилка — два способа связать клиента с требованием
- [decision] **Способ 1 — «Заказчик» (precise):** колонка «Заказчик» в телах Confluence 1.5. Точно, но на сервере/локально только 2 из ~10 страниц (Мосбиржа/ТН/ЦБ, ~90 требований). Полный набор — **у руководителя** (его выгрузка 1.5 с «Заказчик»). Отвечает: «кто официально заказал требование».
- [decision] **Способ 2 — «спрос» (derived, из сервера):** ~782 FR/SR-заявки в `sd_request` (client-меченые, продукт-семейство+текст) → матч к требованию по продукту/компоненту/тексту (fuzzy). Данные УЖЕ есть, руководитель не нужен, покрывает пилотов с заявками. Отвечает: «кто по теме требования обращался/болит» (не «заказал»). Провенанс из ER: FR-заявка → порождает (спрос→бэклог) → Need/Requirement (связь не проставлена); `Need.client` выводима из crm_open_requests.
- [decision] **Гибрид:** показывать оба с пометкой источника — бейдж «заказал» (твёрдо, Способ 1) где есть + «обращался/спрос» (мягко, Способ 2) где нет.

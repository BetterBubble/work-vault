# Дирекция Лебедева/Солонко: фазы RAG для ИВА + MCP для аналитиков

Вводная от **Дмитрия Лебедева** (2026-07-14, 12:23): концепт Шульги идёт в работу, **но с учётом видения Димы Солонко**, для ИВА. Будет встреча по концепту.

## Фазировка (по аудитории/контенту)
1. **Аналитики и техписы** — первый этап.
2. **Сейлы** — второй этап.
3. **Чаты и почта** — третий этап.

## Новое требование
- Нужно сделать **MCP для аналитиков** (отдельный интерфейс). Согласуется с ранним голосовым (3 интерфейса: helm-чатбот; **MCP-тул для аналитиков** с авторизацией phk/tacticum-deploy; встроенный чатбот в Evo/IVA One).

## Как ложится на текущую работу
- **Этап 1 (аналитики+техписы)** = то, что уже строим: **RAG#1** (публичная дока iva.ru/docs — для техписов/аналитиков, УЖЕ в бою) + **RAG#2** (wiki/jira для аналитиков — в коде, не в бою). Интерфейс этапа — **MCP для аналитиков** (экспонирует RAG#2 и/или RAG#1 как MCP-тулы).
- **Этап 2 (сейлы)** — НОВЫЙ RAG/знание для продаж (в моём исходном концепте отдельно не выделялся — добавить).
- **Этап 3 (чаты+почта)** = мой прежний **RAG#3** (чаты/почта).

## Отличие от исходного концепта Шульги
- Исходно: RAG#1 (docs) / RAG#2 (wiki+jira аналитики) / RAG#3 (чаты+почта + ассистент требований).
- Видение Солонко переупорядочивает по аудитории: аналитики+техписы → сейлы → чаты+почта; и явно выносит **сейлов** отдельной фазой и **MCP** отдельным интерфейсом.

## Действия
- Подготовить к встрече обновление концепта под фазы Солонко + место MCP-интерфейса.
- Спроектировать MCP для аналитиков (что экспонирует, auth phk/tacticum-deploy).

# Архив

Сюда переносится **устаревшее и заменённое**, чтобы не мешало текущей работе, но не терялось. Ничего не удаляем безвозвратно — переносим с пометкой.

Контракт фронтматтера — единый, см. `~/claude-stack/memory-protocol.md` §3. Для архива: `status: archived` + `superseded-by: "[[канон-заметка]]"`. Поиск и агенты по умолчанию читают только `current`; архив — для истории и Акта.

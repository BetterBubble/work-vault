# Гейт двух веток: `fix/skill-spec-assets-metadata` и `fix/kmp-role-compose-skills`

**Вердикт: GO по обеим.** Вторая — строго после первой. Блокирующего нет.
Записано лидом со слов гейта: у него в этом заходе не было права создавать файлы отчётов.

## Как проверялась композиция — важен метод, а не только результат

Гейт **не смотрел манифесты**. Эталон установки хранит sha256 отрендеренного тела, поэтому он
посчитал хеши тел из обоих слоёв — стек-лейна и общего UI-лейна — и сверил с тем, что лежит в
эталонах роли. Все четыре навыка в обоих CLI совпали с Compose-версией, не с веб-версией; по одному
пути на идентификатор, дублей нет.

Дополнительно прочитал тела сам:
- **сверка макета** несёт снимок через дерево семантики; оставшийся playwright — осознанная ветка
  для веб-цели, которая действительно рендерит в DOM, а не веб-остаток;
- **работа с токенами** несёт тему Compose, Tailwind и styled-components отсутствуют (в веб-версии
  они есть);
- **проверка UI-конвейера** несёт Compose-словарь, `QLineEdit`/`QML`/`React`/`Vue` отсутствуют
  (в веб-версии есть все четыре).

## Мутации теста паритета — воспроизведены обе

- вернуть общий UI-слой в конец списка зависимостей → краснеют оба оракула, диагностика
  предметная: «отдаёт тела чужого стека: QLineEdit, QML, QWidget, React, Vue»;
- положить веб-тело навыка прямо в стек-слой → краснеют проверка зеркал и проверка стековой
  верности.

Обе мутации откачены, чужие рабочие деревья не затронуты, временное дерево удалено.

## Прочее

- `merge_iva_tokens.py` **не попал ни в один коммит ни одной ветки** — проверено тремя способами.
  В дереве платформенной ветки он лежит незакоммиченным: артефакт чужого стэша, разобран отдельно
  ([[incident-stash-cross-worktree-2026-07-27]]).
- Тела навыков **побайтово идентичны** копиям старого профиля; сам старый профиль не изменён
  ни строкой.
- AI-подписей нет ни в одном из пяти тел коммитов. Абсолютных путей, секретов, мусора — ноль.
- `ruff check` чисто на обеих; `mypy` чисто; дисциплина версий профилей — 48 профилей чисто;
  синхронность зеркал — 68 ингредиентов в 6 парах.
- Первоисточник проверен: схема авторинга разрешала спорное поле **уже на `main`**, в дифф ветки
  она не входит. Значит модель приведена к схеме, а не наоборот — как и заявлено.

## Незакрытое, не блокирующее

1. Ветка 2 оставляет один файл тестов неотформатированным. На `main` уже три таких файла из тех же
   пяти, форматирование не входит ни в один CI-гейт, pre-commit нет.
2. **Скоуп механически не проверен** — файл скоупа гейту не передавался, скрипт честно пишет
   «не проверено». Ручная сверка разрастания не показала, но это суждение, а не проверка.
   Записано прямо, потому что просил честность вместо общего одобрения.

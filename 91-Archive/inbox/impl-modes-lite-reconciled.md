## Три обязательных фикса (тимлид сверил — применены)

1. **Ок-гейт, снят AFK-обход** [CORRECTED]. В драфте v0 было «пользователь AFK → идёшь по
   ордеру». Оригинал ПРЯМО запрещает: «Молчание, „интересно", уточняющий вопрос — НЕ
   аппрув», «Сгенерил ордер и сразу начал — главный запрещённый паттерн». Удалено во всех
   трёх файлах. Правки только после явного гейт-слова (ок/approved/го/делай/утверждаю/
   принято/go/proceed); замечание → поправить ордер, показать дифф, снова ждать «ок».
2. **Диагностика read-only на все три типа** [CORRECTED]. Драфт привязывал её только к
   bugfix. Оригинал (шаг 1) требует для всех: bugfix → корень («ордер без корня не готов»);
   refactoring → blast-radius в ордер+тест-план; feature-S → проверка каждого API + апстрим
   до эмит-сайта.
3. **Убран файл-артефакт закрытия** [CORRECTED]. Драфт конструировал `fix.md` ~10-15 строк
   в `Tasks/<N>/`. Оригинал: «Никаких файлов-артефактов: ордер и отчёт живут в чате;
   `Tasks/<N>/` создаёт только полный цикл». Заменено мини-отчётом в чат (шаг 4).

## Генерализация ([REPO-СЛОЙ])

Вынесены с сохранением механики: инструмент навигации (Serena/codegraph/ccc); модуль /
version catalog; платформенный тест / общий модуль / кросс-платформенная сборка; fragile-

lock-файлы). Принципы (платформенное само-ревью, smoke в fragile-зоне, test-first enforced)
СОХРАНЕНЫ как обязательные с пометкой, что конкретика — из repo-слоя.

## Финальная рекомендация A/B: **Вариант Б**

Отдельный лейн **`tacticum-lite-base`** + отдельный скилл/команда **`lite-task`**, НЕ
расширение fix-bug. Подтверждает провизорную позицию ГД. Доказательство из оригинала (три
независимых факта):
1. Оригинал позиционирован как самостоятельный скилл — «альтернатива полному циклу (5
   артефактов)», а не под-режим bugfix.
2. Оригинал сам ЭСКАЛИРУЕТ в `/start-task` — стоит рядом с полным циклом как параллельный
   вход, не внутри fix-bug.
3. Оригинал включает feature-S (= change) как штатный тип, а инвариант fix-bug
   (restore→fix-bug, change→start-task) это прямо запрещает — совместить в одном лейне без
   разрушения инварианта нельзя.

Плюс Б: bugfix-лейн остаётся restore-only, scope-tripwire НЕ трогается (guardrail «живые
лейны не переписываем» соблюдён).

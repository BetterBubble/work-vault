- Полный downstream (BRD→MOCKUPS→PIN→код→тесты) — по решению ГД не гоним (ТЗ#2 его не менял, тестировать = жечь модель-вызовы без сигнала по ТЗ#2).

- Провижн через каталог (tacticum-mcp) — намеренно НЕ использован (там прод=старый без режимов); контент брался из main-файлов.

# Заглушки, созданные Obsidian по нерезолвимым ссылкам

Пустые заметки, которые **Obsidian создал сам** в корне хранилища, когда кликали по вики-ссылке, собранной из `permalink` вместо имени файла: Obsidian резолвит вики-ссылки только по имени файла, ссылка не открывалась, а по клику рождалась пустышка — и дальше молча собирала на себя входящие ссылки вместо настоящей заметки. Механизм и правило «ссылаться только именем файла» — регламент памяти **§8** (`~/claude-stack/memory-protocol.md`, раздел «Именование» → «Почему ссылка — только по имени файла»).

Все пять убраны 2026-07-25: входящие ссылки перецелены на настоящие заметки, сами заглушки перенесены сюда со `status: archived` и `superseded-by`. Содержимого у них никогда не было. Папка нужна только как след механизма — новые заглушки появляться не должны (правило §9 исправлено); если появились — механизм вернулся.

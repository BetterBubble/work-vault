# Стек и команды — шпаргалка (АРХИВ)

**Заменено на HANDBOOK в личном стеке.** Эта заметка была снимком мира от 21 июля: знала
4 команды из 7, не знала про компанию ролей, канал сигналов, секреты, автономию и доктора,
перечисляла 6 папок из 11 и утверждала про SessionStart то, чего хук не делает. Плюс сама
нарушала правило домов: «как я работаю» не живёт в рабочем vault. Оставлена как история —
отвечать по ней на вопрос «что у меня есть» нельзя.

Карта того, что установлено, какие команды есть и когда что использовать. Открывай, когда забыл. Claude тоже её видит (лежит в памяти).

## Ритм дня (по порядку)
1. **Утро** → `/morning` — подтянуть репо, изменения Taiga/вики за сутки, заметка дня + бриф.
2. **Новый чат / контекст раздулся** → `/catchup` — поднять контекст «где мы сейчас».
3. **Перед созвоном** → запустить запись (см. ниже). **После** → `/after-call`.
4. **Конец дня** → `/wrap` — итог, чекпойнт `session-state`, лог дат для Акта.

## Команды (slash)
| Команда | Что делает | Когда |
|---|---|---|
| `/morning` | Безопасный pull всех репо (грязные пропускает с объяснением) + Taiga/вики за сутки + заметка дня | Раз в день, утром |
| `/catchup` | Собирает бриф из памяти + Taiga + вики, без записи | Новый чат, потерял нить, после раздувания контекста |
| `/after-call` | Разбор транскрипта по глоссарию → показывает на правку → после «ок» пишет в память + Taiga | После каждого созвона |
| `/wrap` | Итог дня, обновляет чекпойнт и решения, лог дат | Конец дня |

## Запись созвонов (transcribe-md)
Две дорожки (You/Them), русская модель, всё локально, файл сразу в память.

- **Твой дейли:**
  ```
  transcribe-md --mic 0 --duration 60 ~/tacticum-vault/00-Board/call-$(date +%Y-%m-%d-%H%M)-daily.md
  ```
- **Смежная команда:**
  ```
  transcribe-md --mic 0 --duration 60 ~/tacticum-vault/00-Board/call-$(date +%Y-%m-%d-%H%M)-other-team.md
  ```
- В конце созвона — **Ctrl+C** в том терминале. Потом → `/after-call` (сам поймёт тип по хвосту имени: `-daily` = полный разбор, `-other-team` = «на касание»).
- Хвост имени важен — по нему `/after-call` выбирает угол разбора.

## Инструменты (MCP)
| Инструмент | Зачем | Как звать |
|---|---|---|
| **Basic Memory** | Общая память десктопа и Code (vault `~/tacticum-vault`) | Само; «запиши/прочитай заметку» |
| **Serena** | IDE-зрение по коду: символы, call-sites, рефактор без грепа | Активировать проект в начале работы по репо |
| **Context7** | Доки библиотек по версиям (FastAPI/Pydantic/Qdrant…) — против галлюцинаций API | Сказать «use context7» в запросе |
| **Taiga MCP** | Тикеты, эпики, статусы | Через команды или напрямую |
| **Wiki MCP** | Страницы вики | ⚠️ путь с префиксом тенанта `tacticum/…`/`cifragen/…`; `search_pages`, НЕ `list_pages` |
| **transcribe-md** | Транскрипт созвонов в память | Команды выше |

## Когда что использовать (быстрый выбор)
- Начал день → `/morning`
- Открыл новый чат / контекст пухнет → `/catchup`, в конце дня `/wrap`
- Прошёл созвон → запись была? → `/after-call`
- Рефактор / перенос кода между файлами/репо, «найди все call-sites», extract в платформу → **активируй Serena**
- Нужен точный API библиотеки → **Context7** («use context7»)
- Лезешь в вики → префикс тенанта + `search_pages`
- Приняли важное решение, которое нигде не записано → обнови память (заметка в `21-Decisions/`) или `/wrap`

## Память: как устроена
Vault `~/tacticum-vault` (Обсидиан + Basic Memory). Папки:
- `00-Board/` — входящее, транскрипты созвонов
- `10-Projects/` — карта репозиториев
- `20-Architecture/` — архитектура, `glossary`, `wiki-mcp-usage`
- `21-Decisions/` — ADR/решения (связаны ссылками = граф)
- `01-Sessions/` — `session-state` (чекпойнт), `daily-*`, `work-log` (для Акта)
- `90-Materials/` — материалы

Контекст переживает переход в новый чат: `/wrap` (или хук PreCompact на длинной сессии) роняет чекпойнт → новый чат поднимает его через `/catchup`/SessionStart.

## Обслуживание
- **Обновить команды** (берёт самую свежую копию, даже если mac добавил « 2»):
  ```
  for name in morning catchup after-call wrap; do f="$(ls -t ~/Downloads/${name}*.md 2>/dev/null | head -1)"; [ -n "$f" ] && cp "$f" ~/.claude/commands/${name}.md && echo "✓ ${name}"; done
  ```
- **Где что лежит:** команды `~/.claude/commands/`, хуки `~/.claude/hooks/`, настройки `~/.claude/settings.json`, конфиг десктопа `~/Library/Application Support/Claude/claude_desktop_config.json`.
- **Бэкапы:** перед каждой правкой конфига делается `*.bak.<timestamp>` рядом — откат копированием.

## Ещё не поставлено
- **Agent Teams** — мульти-сессия, одна сессия командует другими (параллельная работа по репо). Включается `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`.
- **SSH MCP** — сервер «Залог Успеха» из чата вместо ручного терминала (отложено).

## Разгаданные грабли
- **Вики «ambiguous»** → путь обязан начинаться с `tacticum/…` или `cifragen/…`; `list_pages` пустой (баг) → `search_pages`.
- **Mac переименовывает загрузки** (`файл 2.md`) → команда обновления выше берёт самый свежий по времени.
- **MCP/хуки не видны в старой сессии** → перезапустить сессию (новые подхватываются при старте).

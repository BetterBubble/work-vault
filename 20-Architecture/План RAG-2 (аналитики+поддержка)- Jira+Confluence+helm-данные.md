# План RAG#2 (аналитики + поддержка)

**Охват:** RAG#2 = Jira + Confluence + **helm управленческая аналитика**. Аудитория: аналитики + поддержка. Все данные — на нашем сервере (helm). Jira/Confluence-выгрузка ожидается 2026-07-14 (доступ через платформу от Димы). helm-данные уже есть.

**Интерфейсы:** морда `/api/rag2` (helm-чат). **MCP для аналитиков — НА ПАУЗЕ** (идея: влить реализацию в iva-mcp; пока не работаем).

## Потоки (делаем всё, кроме MCP)
- **A — helm-данные в RAG#2** (доступно сейчас): индекс helm-сущностей в новую коллекцию `helm_mgmt`: требования (+вердикты met/partial/absent по трекам, компоненты, клиенты, тесты), SD-запросы (поддержка, ~43k), инициативы, сигналы, эпики/задачи.
- **B — боевой live-MCP транспорт** (сейчас заглушка): streamable-http через iva-mcp, свежесть по ID.
- **C — ingest-пайплайн под выгрузку** (готовим заранее): Confluence extractor (body.storage+вложения)→docproc→структурный чанкинг→embed→индекс; Jira full ingest (поля+changelog+links+attachments), идемпотентно; инкремент.
- **E — golden + eval RAG#2**: профильный golden (аналитики: статусы/связи/обоснования; поддержка: SD/покрытие), адаптация eval-harness (recall@k, answer_in_context, sweep).
- **F — качество морды RAG#2**: перенести уроки RAG#1 (все нужные цитаты, чистый markdown, гейт честного отказа, фильтры проект/тип/статус/компонент, версия/сниппет, max_tokens).

## Порядок исполнения
Волна 1 (параллельно): C, A, E. Волна 2: B, F (rag2-core, чтобы не толклись в application/rag2). Интеграция → ветка → пуш по флоу (push→PR→мерж→деплой). MCP(D) — позже.

## Ждёт данных
Боевая выгрузка Confluence(тела IVAPROJECT+спейсы)+полный Jira scope→прогон C→наполнение→замер E→тюнинг. Реранкер (когда откроют tacticum/rerank)→вкл + vocab-bridge. Scope (IVA One vs весь портфель) — от Димы.

# Helm — Competency Questions (вопросы, на которые отвечает система)

> **Назначение.** DDD-приём: набор вопросов, на которые модель ОБЯЗАНА уметь отвечать —
> критерий полноты домена и одновременно **golden-set для RAG-eval** (v02 §8.3 H).
> Каждый вопрос привязан к: источнику данных (`data/…`), режиму (**D** = детерминированно,
> без LLM / **R** = RAG-LLM / **G** = граф-traversal) и волне (v02 §9).
> Проверено на реальных выгрузках ИВА (снимок 2026-07-03).

Легенда режима: **D** детерминированный (SQL/светофор, Волна 1a) · **G** граф (зависимости/связи) ·
**R** RAG/LLM (текст/контекст, Волна 1b).

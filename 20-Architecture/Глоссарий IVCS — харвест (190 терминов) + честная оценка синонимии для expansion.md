# Глоссарий IVCS — харвест и оценка пригодности для query-expansion

Ночь 2026-07-16, анти-стоп задача (дата-независимая). Источник: Confluence page **149651699** «Глоссарий» (space IVCS, version 88). Цель страницы (дословно): «обеспечить единый вокабуляр в командах аналитики, разработки и тестирования продуктов IVA MCU».

## Формат (факт)
Markdown-таблица `| Термин | Определение | Специфика | Скриншот/Ссылка |`. Колонка «Термин» по регламенту = рус-термин + аббревиатура (через запятую) + локализация в скобках. Специфика ∈ {Common, Web, Desktop, Mobile, Room, Aurora}.

## Результат харвеста (факт)
- **190 строк-терминов**, из них **181 с определением/синонимами**.
- Структурировано в JSON: `{term_ru, abbrevs[], localization[], definition, specificity, raw_term}`. (Сессионный путь scratchpad: `glossary_ivcs.json`; страница тривиально ре-харвестится одним fetch — переген при необходимости.)
- **Синонимия — СКРОМНАЯ:** явная англ-локализация в скобках (RU↔EN, тип «Видеоконференцсвязь/ВКС (videoconferencing)») — лишь ~4; аббревиатура↔полная форма (SIP↔Session Initiation Protocol, LDAP, MCU, SFU, RTCP, DTMF, GSM, SMTP…) — ~17. Остальное = термин→определение без явных синонимов.

## Честная оценка для дизайна (важно)
- Глоссарий **определительный, а не синонимический**. Ожидание пользователя («заказчик пишет "видеозвонок" — в системе "conference session"», расширение запроса синонимами) этим корпусом покрывается **частично**: сильно для аббревиатур (SIP/LDAP/MCU), слабо для разговорных RU↔EN пар.
- → **Подтверждает ранее принятое решение: query-expansion держать ЗА eval-гейтом (precision).** Сигнал модест; включать expansion «на авось» нельзя — сначала измерить на golden, что recall растёт без падения precision. Если и включать — начать с надёжного среза: аббревиатура↔полная форма (детерминированный, безопасный), НЕ разговорные синонимы.
- Полезный побочный продукт независимо от expansion: 181 определение = материал для **докстрингов/подсказок тулов** и для FR-скилла (что значит термин из постановки), и потенциально для `docs_ask` по внутренней терминологии.

## Статус
Харвест сделан (данные есть, структура ясна). **Expansion НЕ включаю** — за eval-гейтом (нужен retrieval-golden, а он ждёт схождения jira-данных). След. шаг по глоссарию: когда eval-фундамент готов — A/B аббревиатурного expansion на golden, включать только при росте recall без потери precision.

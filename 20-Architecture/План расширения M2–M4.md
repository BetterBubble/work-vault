# План расширения M2 → M4 (после рабочего M1 на сервере)

**Источник на диске:** `~/tacticum/fast_task/2_План_расширения_M2-M4.md`
**Тип:** операционный план. M1 доказан на сервере; ниже — утолщение работающей трубы по фазам ADR.

## Что уже работает (M1, зафиксировано)
docproc (извлечение+OCR) · чанкинг 900/150 · реальные эмбеддинги `tacticum/embed` (батчами по 4 — лимит bge-m3) · Qdrant + fail-closed `tenant_id=zu` · semantic-поиск · LLM-ответ через Gateway (не-стрим) · цитаты с номером страницы · мок-OIDC · контейнер на сервере.
**Моки, ждущие замены:** OIDC, `open_url` (presigned S3), стрим.

## M2 — ширина
Снять моки M1 (реальный OIDC через project-hub: `ProjectHubScopeResolver` вместо `MockScopeResolver`, валидация `phk_`-токена через `POST /api/internal/resolve` service-key'ом; тенант из ответа hub, fail-closed остаётся) + форматы docx/xlsx + аудио через transcription. Затем M3 — качество (eval golden-set + тюнинг), M4 — харднинг + прогон демо.

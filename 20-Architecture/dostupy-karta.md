# Карта доступов

**Здесь НЕТ значений.** Ни токенов, ни паролей, ни ключей — только имена, назначения и границы.
Значения лежат в Keychain macOS и достаются по имени:

```bash
secret list                        # какие имена есть
secret get  <имя>                  # значение в stdout
secret env  <имя> -- <команда>     # значение в $SECRET, в stdout не попадает — предпочтительно
secret set  <имя>                  # завести/обновить (спросит значение без эха)
```

Почему так, а не файлом со всеми значениями: агент штатно читает недоверенный контент — тикеты и
вики заказчика через `iva-mcp`. Prompt injection из такого текста может склонить его вставить
токен в заметку, вики или PR. Keychain убирает сам файл: значение зашифровано, `cat` его не
достанет, агент получает **один** секрет по имени. Значения не идут в git **никогда**, даже в
личный репозиторий: приватный репо это не шифрование, и после ротации значение остаётся в истории.

## Секреты

Заполняется по мере переноса в Keychain. Пока значения живут в `~/.claude.json` (пять токенов
`Authorization: Bearer` в определениях MCP-серверов) — их надо перенести и ротировать, потому что
они лежали открытым текстом и были читаемы любым агентом.

| Имя в Keychain | От чего доступ | Хост / сервис | Границы | Кто выдал | Ротация |
|---|---|---|---|---|---|
| `taiga-token` | трекер Taiga | `project.cifragen.ru` | чтение/запись задач; проекты перечислены в `profiles/tacticum.md` | *уточнить* | *не ротировался* |
| `wiki-token` | Wiki.js | `wiki.cifragen.ru` | тенанты `tacticum` и `cifragen`; префикс пути обязателен | *уточнить* | *не ротировался* |
| `iva-mcp-token` | Confluence + Jira **заказчика** | `mcp.tacticum.ru` | **только чтение.** Источник недоверенного контента — из него возможна prompt injection | *уточнить* | *не ротировался* |
| `helm-analyst-token` | собственный MCP аналитика | `mcp.tacticum.ru` | чтение знаний, C4-топология, реестры API | свой инструмент | *не ротировался* |
| `iva-confluence-pat` | сервисный PAT Confluence | лежит на `adp_emb` в `/opt/iva-mcp/env` | **read-only.** Значение на сервере, не у нас — сюда попадает только если понадобится локально | заказчик | *уточнить* |

| `gateway` | LLM-шлюз (`llm.cifragen.ru`, LiteLLM + Traefik) | эмбеддинги, реранк, генерация | чтение статуса | менять маршрутизацию без ADR |
| `zu_demo` | демо-стенд ЗУ (клиент «Залог Успеха») | демо и проверки | *уточнить* | *уточнить* |

Деплой-юзер: `tacticum-deploy`, его ssh-конфиг с `adp-jump` — на `helm`.
Туннель к `triva`: `systemd SSH 127.0.0.1:<port> → adp_emb → 10.0.196.14:9034`.

**Правила ssh для агента.** Мутирующие операции (`ssh_execute_sudo`, `ssh_deploy`, `ssh_db_import`,
`ssh_backup_restore`, `ssh_upload`, `ssh_sync`, `ssh_process_manager`, `ssh_key_manage`,
`ssh_tunnel_create`) запрещены правилами. `ssh_execute`, `ssh_db_dump`, `ssh_db_query` — с
подтверждением. Read-only (`ssh_list_servers`, `ssh_service_status`, `ssh_tail`, `ssh_health_check`,
`ssh_db_list`) разрешены. Kill-switch: `~/.claude/AUTONOMY_OFF` глушит все прод-действия сразу.

## Если секрета нет

1. `secret list` — посмотри, что вообще заведено; имя могло отличаться.
2. Нашёл в этой карте, но нет в Keychain — попроси Президента завести: `secret set <имя>`.
3. Нет ни там, ни здесь — **не изобретай обходной путь и не проси положить токен в файл.**
   Скажи прямо, какой доступ нужен и зачем; заведение секрета — его шаг.

## Что требует уточнения Президентом

Помеченное *уточнить* выше я вывел из профиля работы и заметок vault, а не знаю достоверно.

Отдельно: пять токенов из `~/.claude.json` **ещё не перенесены** в Keychain и **не ротированы** —
они лежали открытым текстом и были читаемы любым агентом. Перенос зависит от того, умеют ли
MCP-серверы подставлять переменные окружения в конфиге (тогда значения уедут в Keychain, а
`~/.claude.json` перестанет их содержать).

**Проверить это я не могу — и это хорошо:** правило `deny` на чтение `~/.claude.json` через Bash
сработало против меня самого, когда я попытался посмотреть формат конфига. Защита работает не
избирательно. Значит шаг твой: либо посмотреть формат сам, либо разрешить разово.

# Helm — два вспомогательных документа для срезов: Карта срезов + Реестр данных по сущностям

Придумано 2026-07-07. Две спецификации, которые собираем ПЕРЕД стартом Фазы 1, чтобы убрать повторную разведку данных на каждой вертикали. **Статус: запланировано, ещё НЕ сделано** — делать в новой сессии.

## Зачем (оценка пользы)
- [decision] Сейчас при каждой вертикали заново копаемся в CSV (какой файл, колонка, ключ). Эти два документа превращают это в «посмотреть в справочник» → сильно ускоряют внедрение всех срезов, окупаются уже на первом (инциденты). Часть контента уже есть разрозненно (аудит data/real, `concept-entity-provenance.md`, `concept-entities.md`) — это их **консолидация**, не с нуля.

## Документ 1 — Карта срезов (`data/slices-map.md`)
- [spec] **1 срез = 1 вью дашборда.** Секция на срез, поля: Срез(вью)+роль · Что показывает (выводимые данные вью) · Сущности (какие из 30 живут) · Связи (какие рёбра нужны) · Источники (файлы data) · Готовность (что в коде / что дописать).
- [spec] Предварительный список 7 срезов: (1) Инциденты/SLA — COO; (2) Бэклог/Потребности — CPO; (3) Портфель/Монитор ГД — CEO/COO; (4) Дефекты/Соответствие — CIO; (5) Ценность людей — COO/HR; (6) Sales/Pipeline — CCO; (7) Task Management — PMO.

## Документ 2 — Реестр данных по сущностям (`data/data-registry.md`)
- [spec] Секция на сущность (30). Формат: таблица «файл · какие поля/колонки в нём (id, P1-P3, продукт, клиент, тариф…) · ключи связи (join-ключи) · заполненность · примечания (что готово/чего нет)».
- [spec] Пример (Обращение/Инцидент): `crm_open_requests.csv` (id SR/FR/IS, Тип, Статус, Возраст, Продукт, Клиент, Код клиента, Контракт, Тариф, Приоритет P1-P3 (85% P3), Исполнитель, Заголовок, Решение 22/782; ключи: Код клиента→Клиент, Продукт→Продукт, Исполнитель→Человек, Контракт→Контракт) · `sd_tasks.csv` (журнал, бедный, не источник) · `critical_cases.csv` (острые 15) · `fr_backlog.csv` (бэклог фич 51).

## Связка
- [note] Реестр = «что где лежит» → питает Карту срезов = «что из этого в каком вью» → обе = спецификация для кода Фазы 1 (ingest→domain→application→router→web) без повторной разведки.

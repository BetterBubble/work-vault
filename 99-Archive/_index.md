# Архив

Сюда переносится **устаревшее и заменённое**, чтобы не мешало текущей работе, но не терялось.
Ничего не удаляем безвозвратно — переносим с пометкой.

## Контракт статусов (фронтматтер заметок)
Каждая содержательная заметка помечается во фронтматтере:
- `status: current` — актуальный канон, единственный источник правды по теме.
- `status: draft` — черновик/сырьё, ещё не канон.
- `status: archived` — устарело/заменено, лежит здесь.
- `updated: YYYY-MM-DD` — дата последней содержательной правки.
- `superseded-by: [[путь-к-актуальной]]` — на что заменено (для archived).

Агенты и поиск по умолчанию читают только `current`. Архив — для истории и Акта.

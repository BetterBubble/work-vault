# Переписка группы «ИИ дизайн-система», 27.07 (сырьё)

Скопировано Президентом. Это **первоисточник постановки** — при сверке сделанного опираться на него,
а не на пересказы.

---

**Корнюшин Пётр.** Договорились о следующем: @Шереметьев Александр описал @Шульга Александр тот
способ, которым была реализована ДС в вебе ИВА One. Входным артефактом в ИИ является **страница
Figma (не скриншот)**. На выходе должны получаться **отчуждаемые компоненты ДС**, на основе которых
строится интерфейс. Так же ИИ должен понимать, **как заменить текущую реализацию похожего компонента
внутри приложения вне ДС на компонент из ДС**. Артефактом темизации является **json файл с описанием
токенов**, который при запросе заказчика предоставляется командой дизайна и **подменяется на сервере**.

@Шереметьев Александр — проверить, как обстоят дела с KMP, и организовать подобный файл, чтобы
помимо wasm+js был ещё json файл с токенами и сам механизм был рабочим.

**Лебедев Дмитрий.** Привет, задача как можно быстрее добавить опцию как в legacy по работе с
дизайном для KMP-клиентов, настроить профили (@Шульга Александр уже сделал, надо проверить),
обучить, применить актуальные правки от @Крыкин Петр и **за неделю обновить дизайн на KMP** и, по
возможности, в legacy. @Корнюшин Пётр — ты лидируешь активность.

**Корнюшин Пётр.** Legacy для веба всё готово уже сейчас. То есть описанная схема **работает в вебе
и десктопе. В мобилах нет**.

**Корнюшин Пётр.** Для мобил скорее всего потребуется доработка бэка, так как не ясно, где и как
хранить тему.

**Крыкин Пётр** (файл `export-tips.md`, см. [[export-tips]]). «Артефактом темизации является json
файл с описанием токенов» — если будете встраивать свою забиралку токенов по API, написал микрогайд,
как не повторить моих ошибок в подобной задаче.

**Корнюшин Пётр → @Лебедев Дмитрий.** План жёстко поменять? или сделать кастомизируемым? В том
смысле, что нужен механизм подложить в процессе работы? или управлять на бэке? Централизованно для
всех приложений компании? или один дизайн для всех без вайт лейбл?

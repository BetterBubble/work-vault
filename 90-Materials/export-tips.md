инструкция на основе граблей из плагина https://www.figma.com/community/plugin/1537033257616082062/var-exporter:

> - Сначала собери типизированную модель `collection → mode → variable`, индексируя всё по ID; имена используй только для отображения/отчётов, если они предполагаются.
> - Резолви значение для каждого режима. В межколлекционных алиасах нельзя передавать `modeId` исходной коллекции целевой: режим задаётся отдельно для каждой коллекции.
> - `resolveForConsumer` требует `SceneNode` с явно выбранными режимами; второй аргумент `{modeId}` API не поддерживает. Для цепочки алиасов фиксируй полный mode-context. [Документация Figma](https://developers.figma.com/docs/plugins/api/properties/Variable-resolveforconsumer/)
> - Алиасы резолви рекурсивно с кешем, защитой от циклов и отдельными ошибками для отсутствующих/недоступных целей; не подменяй ошибку строковым значением токена.
> - Дедуплицируй только по ID. После нормализации имён (если внедрена) обязательно проверяй коллизии; не объединяй токены просто из-за одинакового имени или значения.
> - Не склеивай структурные ключи вроде `collection - mode`: храни поля раздельно — разделитель может встретиться в названии.
> - Сохраняй исходные типы и точность; заранее зафиксируй формат цвета и альфы. JSON создавай через `JSON.stringify`.
> - Явно задай политику для hidden, remote/library и inherited variables; не превращай ошибку чтения в «пустой набор токенов».

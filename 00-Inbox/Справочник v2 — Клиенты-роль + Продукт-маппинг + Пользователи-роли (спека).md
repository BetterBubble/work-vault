Принцип доставки правок (важно для дизайна): правка → сразу в БД, защищена от пере-сида; до вью — либо **live** (роутер/auth читает справочник при запросе), либо **refresh** (пересчёт витрины). Подтверждённое оператором = доверенная запись (ingest использует её, а не гадает).

## 1. Клиенты / Компании (канон + роль) — чинит «грязных клиентов»
- Вкладка «Компании» в Settings: список канон-компаний (`company`), у каждой **роль `CompanyRole`** (мы/клиент/партнёр/—) + алиасы (сырые написания). Действия: задать роль, слить дубли (алиас→канон), подтвердить алиас.
- **Live-фильтр:** роутер ServiceDesk `by_client` и `clients-money` фильтруют компании с ролью **'клиент'** (исключают мы/партнёр/внутренние) — читают `company_role` ПРИ ЗАПРОСЕ → пометил ИВА='мы' → сразу исчезла из клиентских разрезов. НЕ требует пере-сида.
- **Доверенный алиас:** подтверждённое «сырой client-string → канон company» ложится в alias-таблицу (confirmed); резолв `sd_request.company_id`/деньги при СЛЕДУЮЩЕМ ingest берёт confirmed сначала, фаззи — только для неизвестных. Дать кнопку «Пересчитать привязки» (пере-резолв company_id) для мгновенности.
- Аудит — `refdata_audit`.

## 2. Продукт-маппинг «сырое имя → канон»
- Таблица `product_alias` (raw_name PK → canon product FK). Вкладка «Маппинг продуктов»: CRUD.
- `domain/product_catalog.ProductCatalog` читает `product_alias` из БД (в дополнение/вместо хардкода). Применяется при **refresh** (канон материализуется в ingest). Пометить в UI «применяется при пересчёте», дать кнопку пересчёта продуктовых витрин.
- Аудит.

## 3. Пользователи / роли доступа (заменяет ручной .env-allowlist)
- Таблица `user_role` (email → role; роль из набора CEO/COO/CPO/CIO/CCO/HR/viewer/full_access). Вкладка «Пользователи·Доступ»: CRUD.
- **auth читает live:** `require_user`/`principal_for_tenant` берёт роли из `user_role` (в дополнение к memberships из resolve + env-allowlist как fallback) → правка роли действует со следующего запроса, без пере-сида и без правки `.env`.
- Гейт: править пользователей/роли — только full_access/admin.

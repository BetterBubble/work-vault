Список запросов к IVA для полной готовности 1a и старта реального 1b. Основа — канон [[control-tower-v02]] §13, сверено с фактически пришедшими данными. Продолжение [[2026-07-03 — Helm- внедрение курированного датасета (Agent Team)]].

## Уже есть (не запрашивать)
- [have] Реальные git-метаданные ИВА (`data/repos/`: 435 коммитов, 145 merge, 8 репо→продукт) — но БЕЗ кода. #wave-1b
- [have] Обезличенный демо-датасет (для безопасной разработки/тестов пайплайна). #dataset
- [have] 3 Confluence-страницы (контекст требование↔Jira↔клиент). #context
- [have] RE-зависимость доступна (topology/dedup/sbom/profile_gen). #wave-1b

## Блок 1 — чтобы «поехал» реальный 1a (запросить первым)
- [request] **Реальный Jira-экспорт** — по задаче: ключ, статус, ассайни(email), эпик/родитель, лейблы, тип, SP, даты (постановка/дедлайн), приоритет, проект. Формат: CSV/JQL-export ИЛИ read-API-токен. У кого: Jira-админ / PMO. Чувствит.: низкая. Разблокирует: реальный 1a + Т1 (commit→task) для 1b. #jira
- [request] **Блоки + ЕОЛ** (кураторская нарезка): block_id, ЕОЛ(email), основной продукт/поколение, флаг cross, команды. У кого: **CEO/CPO** (решение). Без этого дерево ответственности пустое — риск №1 канона (§12.0). #blocks
- [request] **Реальные цели** (список приоритетов). У кого: CEO/CPO. #goals
- [request] **Состав команд**: person_email↔ФИО↔команда (если нет — соберём черновик из Jira/git). У кого: тимлиды/HR. #teams

## Блок 2 — «важно/деньги» для 1a
- [request] **Продажный список / CRM-экспорт**: клиент×продукт×сумма×вероятность стадии×дедлайн×стадия. У кого: Sales Ops / коммерческий блок. Чувствит.: ⚠ коммерч. #sales

## Блок 3 — для реального 1b (ценность команд/ФИО)
- [request] **GitLab PAT** с доступом к группам `iva/*, ivcs/*, imail/*, rn/*, terra/*` — для полного PR/MR API (title/reviewers/status/approvals; сейчас только merge-коммиты как прокси). У кого: DevOps/GitLab-админ. #git #blocker
- [request] **repomix код-снимки** по репам (P0-список) — для RE-обогащения (topology→work→product, dedup→дубли, SBOM→поколение). Обещаны «позже». У кого: DevOps (read-доступ к репам). #repomix #blocker
- [request] **Карта идентичности**: единый email человека во всех системах (Jira/git/HR); учесть внешних подрядчиков (@nwire.ru/@gmail.com). У кого: IT/IdP-админ (project-hub). Чувствит.: ⚠ ПДн. Риск №1. #identity
- [request] 🔴 **Штатка**: ФИО, команда, роль/грейд, руководитель, статус. У кого: HR. ⚠ ПДн. #red
- [request] 🔴 **Зарплаты** по ФИО (оклад/ФОТ). У кого: HR/C&B. 🔴 высокая, только вручную оператором. #red
- [request] 🔴 **CV**: навыки/стек, грейд, опыт. У кого: HR/рекрутинг. ⚠ ПДн. #red
- [request] **Юнит-экономика/маржа по продуктам**. У кого: финблок. ⚠ финанс. #economics

## Решения (не данные, но нужны)
- [decision-needed] **Хостинг чувствительного снимка** (§12.7): периметр IVA on-prem vs наш контур на время MVP + контуры доступа (🔴 узкий круг CEO/CPO/HR). Решить ДО заливки реальных зарплат/CV. #governance
- [decision-needed] **OIDC/project-hub + деплой 1a** — где хостится апп, аутентификация. #infra

## Порядок (минимум, чтобы поехать)
1. Jira-экспорт + блоки/ЕОЛ + цели + состав команд → граф + дерево ответственности (реальный 1a).
2. + CRM/sales → важность/деньги + дедлайны.
3. + GitLab PAT + repomix + идентичность → 1b git-ingestion + RE.
4. + 🔴 HR (штатка/зарплаты/CV) + решение по хостингу → скоринг ФИО (1b красный контур).

# Решение: кто пишет тест-кейсы

**Дата:** 2026-07-23 (созвон, руководитель Дима Солонко + Саша). Статус: approved.

## Решение
**Тест-кейсы пишут аналитики** (расширенные юз-кейсы + тест-кейсы), **QA/тестировщики дополняют на ревью** (добавляют неочевидные сценарии). Авторинг с нуля — НЕ у QA.

## Обоснование
Пирамида тестирования: максимум тестов на юнит-этапе. Инфа (сценарии/TC) должна быть в фичер-реквесте ДО разработки, чтобы разработчик покрывал юнит-тестами. Если TC пишет QA в конце — поздно. «Первый слой» (тест-дизайн) у аналитиков почти весь уже есть → добавить дёшево.

## Что меняет в профилях
- **Профиль аналитика** — добавить скилл «расширенные юз-кейсы + тест-кейсы» + ревью фичи-реквеста.
- **Профиль QA (`iva-role-qa`)** — остаётся **исполнение/автоматизация** автотестов (9 скиллов + 3 субагента) + **ревью-дополнение** TC (не авторинг). `tests-authoring` живёт у аналитика, шарится.
- Долгосрочно (Дима): аналитики пишут всё, тестировщикам остаётся реализовать тест-кейсы.

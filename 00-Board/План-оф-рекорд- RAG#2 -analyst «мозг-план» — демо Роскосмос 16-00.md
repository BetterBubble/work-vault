# План-оф-рекорд: RAG#2 `/analyst` «мозг-план» — демо Роскосмос 16:00

Направление **RAG#2** (новое). Рабочая точка `helm.tacticum.ru/analyst`. Всё лепим к RAG#2. Ветка `feat/rag2-analyst-sintez` (от `main`). **autonomy: off** — PR и деплой `/opt/helm` делает пользователь сам; я/лид — до controller-гейта.

## Цель и критерий успеха
Веб `/analyst` отвечает **синтезом** «Статус → Сделано / В процессе / Не начато → Как технически сделать → Кому задача → Что уточнить» с цитатами `[n]`, по реальным данным ИВА. **Критерий «получилось»:** демо проходит по 6 актам гладко + живое отклонение (Акт 7) держит.

## Технический план (grounded)
Новый **`POST /api/rag2/answer`** = надмножество `Rag2ContextOut` + `synthesis`/`synthesis_failed`/`topology`/`tests`. `/context` не трогаем (живой фолбэк).
- Синтез: `TrivaLlm`/`GatewayClient.chat` (не-стрим, `iva_llm_*`, туннель 127.0.0.1:8790, модель triva). Промпт `SYNTH_PROMPT` с жёсткими рубриками, строго по контексту, анти-галлюцинации (эталон — `docs_assistant.py`).
- Guardrail: нет hits → triva не зовём. **Таймаут-guard** `asyncio.wait_for ~25с` из-за стекинга ретраев gateway (до ~90с). Любая ошибка синтеза → `synthesis_failed=true`, фолбэк на context (HTTP 200).
- B: in-process `arch_map`/`affected_systems` (через `_with_session`) → компактный `topology` в промпт.
- C: `requirement_tests` → только счётчики ТК/`automated`; снапшот пуст → `tests=None`.
- D: включить `iva_docs__bge_m3_1024` в `_corpora_hits`/`build_rag2_context`/`_doc_from_payload`/`federate`/`SOURCE_LABELS`; риск дублей docs↔confluence и веса в RRF.
- **Порядок A→UI→B→C→D. Cut:** A+UI обязательно; B важно; C, D — stretch.

**Критические файлы:** `src/helm/interface/api/routers/rag2.py` · `src/helm/infrastructure/rag2/service.py` · `src/helm/infrastructure/assistant/service.py` (`TrivaLlm`) · `src/helm/application/docs_assistant.py` (эталон промпта) · `src/helm/interface/mcp/analyst_server.py` (хелперы B/C) · `web/src/screens/AnalystChat.tsx` (+`api.ts`,`types.ts`).

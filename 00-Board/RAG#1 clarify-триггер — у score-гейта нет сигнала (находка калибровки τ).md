# RAG#1 clarify: у score-гейта нет сигнала (замер на проде, 2026-07-20)

Калибровка τ для Ф2-clarify вскрыла: **триггер по top-score реранка не работает.** Замер на проде (helm).

## Данные
- Распределение top-score реранка: **реальные golden-запросы 0.98–1.00** (медиана 1.000, n=40); **мусор/офф-топик 0.000–0.002** (n=6). Между 0.002 и 0.984 — ПУСТО (бимодально).
- Порог tau_answer=0.55/tau_floor=0.30 → полоса clarify (0.30–0.55) пустая → clarify почти никогда не сработает.
- Разнообразие продуктов в топ-4: шумное. Неоднозначные крафт-запросы иногда 1 продукт (уверенный ответ есть), а явные golden-запросы иногда 2-3 продукта → ложные срабатывания. Пример: «как безопасно сменить пароли» (явный) → CS+MCU оба ~0.999; «как добавить участника» (неоднозначный) → IVA One+MCU оба ~0.998.

## Вывод
Чистого дешёвого автосигнала «переспросить» из реранк-скоров/продукт-диверсити НЕТ. `decide_retrieval_action` по score-порогу (как построено в Ф2) в реале либо молчит, либо ложно переспрашивает (UX-риск).

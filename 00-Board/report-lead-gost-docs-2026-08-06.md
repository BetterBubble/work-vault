# Чекпойнт lead-gost-docs — 06.08

Сессия вела **две темы**. Обе на паузе до решений Президента.

## Где стоим

**1. ГОСТ-документация (моё направление).** Постановка переопределена дважды за день —
созвоном с НТЦ и переписки с Леонидом. Разведка закончена: MVP собирается из готового
(`word-mcp` для DOCX, `triva` для текста и зрения, helm для чтения), закрытый контур возможен.
Кода нет, доступов нет. Задача **третья в очереди** по решению ГД; порядок задан:
**сначала руками собрать документ, потом концепт** — план крупной задачи писать рано.

**2. Заявка ИНТЦ на налоговую льготу** (не моё направление, разовое поручение). Глубокая
разведка семью агентами закончена, 19 предложений с доказанным заделом под каждым.
Срок Завьялова — **край утром 07.08**.

## Следующий шаг

- **По заявке:** текст для чата отдан Президенту, разбит по двум продуктам. Если нужно —
  довести до формата НИР (новизна → методы → этапы с актами испытаний).
- **По ГОСТ:** дождаться ответа Леонида по доступу; без доступов можно проверить на нашем
  `.docx` три вещи, которых они боятся — переваривает ли `word-mcp` 180 страниц со 150
  картинками, узнаёт ли `triva` интерфейс на скриншоте, находятся ли битые ссылки и сбитая
  нумерация. **Предложено Президенту, ответа нет.**

## Что заблокировано

- доступ к материалам НТЦ — запрашивает человек, ответа Леонида нет;
- контур их Jira/Confluence: Data Center или Cloud — не спрошено, от этого зависит вся оценка;
- **два фолбэка в Google Gemini взведены** (`gateway config.yml:140` и прод helm
  `HELM_RAG2_SYNTH_FALLBACK_LLM_MODEL`) — пока живы, «только наша модель» неверно. Решение
  Президента, прод;
- квоты на `triva` — их нет, модель делит железо с ВКС-стенограммами (владелец sys-terra).

## Что отсеяно — не делать

- **генерацию документов с нуля** — «у нас нет потребности, мы всё делаем по эталонам»;
- **PDM, архив, согласовалки, паспорта, бумажный хвост** — вне границы MVP обеими сторонами;
- **конструкторскую документацию** — закрыта, наружу нельзя, скоуп только программная;
- в заявке: **диаризацию, карточку итогов, дипфейк-детекцию, китайский и арабский** — всё
  в проде, часть лицензируется с 2024;
- **NPU-формулировку** для Largo — ноль коммитов, источник только фраза техписа.

## Ключевые факты

- у НТЦ на всю документацию **1,5 человека + Леонид**; нехватки рук нет, справляются;
  выигрыш он сам оценил в **10–20%** с условием «если тяжело — не окупается»;
- **с четверга Леонид в отпуск**, остаётся Ангелина — окно на «пощупать» узкое;
- `triva` = Gemma-4: **function calling, зрение с OCR, стриминг, 128K** — проверено ~25
  живыми вызовами; короткий запрос 1 с, prefix-кэш 0.3–0.7 с;
- **GPU у нас ноль** на всех 7 серверах — свой инференс поднять не на чем;
- в заявке самое ценное: TTS в релизе без потребителя · перевод на 53 языка уже в коде ·
  диалоговый ассистент готов кроме UI · ONNX-движок в клиенте крутит одну модель ·
  CV-конвейер меняется подменой URL · `SCORE-658` и `SCORE-662` — спрос от продаж.

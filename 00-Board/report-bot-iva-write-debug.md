## Что заблокировано

- **Фолбэк источников** в «Поддержке» — решение по данным после замера, см. следующий шаг.

## Ключевые факты

- **Платформа НЕ шлёт `author.login`** — в событии только `profileId`, `type`, `name` (снято
  перехватом боевого трафика). Личность выводится из имени через справочник Jira, при
  единственном совпадении в доменах `iva.ru`/`tacticum.ru`/`iva-tech.ru`.
- **Голый адрес в сообщении не кликается**, кликается только `link`-блок — поэтому оформление
  блоками включено по умолчанию.
- **Деплой разорван между аккаунтами:** deploy-ключ GitHub на сервере не принимается
  (`Permission denied`), код тянет `tacticum-deploy`, docker-команды идут от root, потому что
  этот аккаунт не в группе docker. Стоит починить отдельно.
- **Красный main между веерными мержами** — ожидаемое состояние, а не случайность: сторож
  разметки требует регистрации каждого текста, ветки по отдельности зелёные. Проверять main
  ПОСЛЕ каждого мержа.
- На проде лежит `src/helm/ingest/mr_source.py`, которого нет в git (от 04.07), плюс каталоги
  `_front/`, `_incidents/`, `_run/`, `bin/`. Разбор не заказан.

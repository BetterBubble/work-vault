# Бриф для verifier — RAG#2 /analyst «мозг-план» (демо Роскосмос 16:00)

Заготовка лида. Гонять ПОСЛЕ мержа UI-ветки в `feat/rag2-analyst-sintez` и деплоя на дев/или локально против прод-данных. Проверка на РЕАЛЬНЫХ данных ИВА (tenant=iva), не фикстуры.

## Что проверяем
Новый `POST /api/rag2/answer`: синтез «Статус → Сделано/В процессе/Не начато → Как сделать → Кому задача → Что уточнить» с цитатами `[n]`, + фолбэк на context при сбое синтеза. UI: панель синтеза над цитатами + «Синтезирую…» + фолбэк.

## Демо-вопросы по 6 актам (реальные данные ИВА)
1. **SSO / IVA ID** — «статус фичи единого входа (SSO), что готово и что осталось» → ждём killer-кейс `IVAONE-12438` (Готово, «Заказчик РосКосмос AD+ALDpro»), 1.0-455 partial (ADFS/SAML), контейнер `id` (форк Keycloak), тестов нет→как план.
2. **Мессенджер / федерация** — «статус федерации мессенджера между организациями» → статус чатов/тредов (Алроса/ЦБ), топология `fedgw`+`ivcs-server` (Медведев/Родионов), 160 ТК (не автомат.).
3. **ВКС / MCU** — «что реализовано в видеоконференцсвязи (транскрибация/демонстрация)» → met готово; ⚠️ НЕ трогать запись/скачивание (Rejected+403). 249 ТК, прогона нет.
4. **Звонки / IVA CS** — «статус SIP-телефонии и покрытие тестами» → SIP partial, SIP-trunk absent; ЧЕСТНЫЙ тест-слайд: **96 ТК, 40% зелёных (26✓/37✗)**.
5. **Календарь + Диск** — «статус Диска и Календаря» → Диск = сильнейшая архитектура (One Disk Go + DS Java/Quarkus+S3, DLP), Календарь partial (228 ТК), Диск-тестов 0.
6. **Почта + Terra** — «статус почты (Phoenix/JUMP) и AI-функций Terra» → Почта (Бабаев, XIMSS→JUMP, 748 ТК крупнейший); Terra (Воронин) топ-AI, перевод `IVAONEHALF-103` Переоткрыт + блокер `611`.
7. **Живое отклонение** — свободный вопрос вживую: «сравни риски SSO и федерации к сроку» ИЛИ «дай план доведения любого partial-требования» → синтез должен держаться (мозг, не скрипт).

## Acceptance (вердикт vs ожидание)
1. Вопросы по актам → синтез-ответ (A) с цитатами; «как сделать» подтягивает топологию (B).
2. Тесты (C) — только счётчики/покрытие; зелёные % НЕ обещать (реально зелёные лишь Звонки 40% и Почта 3/3).
3. Q7 (отклонение) — синтез держится.
4. **triva-нагрузка:** мини-серия параллельных запросов — стабильна; при таймауте → фолбэк на context, НЕ 5xx, НЕ зависание (проверить таймаут-guard ~25с).
5. `/iva-docs` (RAG#1) жив; вход tenant=iva у презентующего работает.
6. `/context` не сломан (регресс-проверка — живой фолбэк).

# Что изменено

`/Users/bubblemac/tacticum-worktrees/helm-get405/src/helm/interface/mcp/iva_write_surface.py:1044`
— внутри `surface`, в ветке `if handshake and not credentials:` (строка 1016), **перед**
`await _handshake_reply(send, call)`:

```python
if str(scope.get("method", "")).upper() != "POST":
    await send({"type": "http.response.start", "status": 405, "headers": [
        (b"allow", b"POST"),
        (b"content-length", b"0"),
    ]})
    await send({"type": "http.response.body", "body": b"", "more_body": False})
    return
```

Метод из ASGI-scope, как и просили, — не из тела. Регистр приведён (`.upper()`): ASGI
отдаёт метод в верхнем регистре, но полагаться на это без нужды не стоит, а цена — один
вызов.

**Одно отступление от буквы задания, называю явно:** в ответ добавлен заголовок
`Allow: POST`. RFC 9110 требует его у 405; клиенту он безразличен — референсный клиент
выходит по коду (строка 102 `if (response.status === 405) return;`), тело и заголовки не
смотрит. Поведение от этого не меняется, но если считаете лишним — снимается одной
строкой.

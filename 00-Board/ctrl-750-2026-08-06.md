Причина: **`ingredient.v1.schema.json` не подключён ни к одному рантайм-пути.**

  `seed_profile.IngredientPayload.metadata` — просто `dict[str, Any] | None`.
- Единственное место, где схема применяется к настоящим манифестам, — 5 профильных тестов
  (`tacticum_dev_base`, `tacticum_ui_base`, `iva_ios_brownfield`, `iva_brownfield_mail`,
  `firebird_web_brownfield`) **из 64 профилей в `templates/`**.

**Вывод по пункту:** автор нового профиля (или любого из 59 профилей без своего теста)
по-прежнему может объявить `metadata.assets`, засеяться и получить молчаливый успех — ровно

а она применяется только в тестах и выборочно. Правильный добор — отдельной задачей:

другой скоуп и другой риск (провалидировать 64 профиля разом почти наверняка вскроет ещё

## 7. Инвариант зеркала — прошло, дыры нет

Проверил не чтением, а прогоном самого теста
`test_metadata_fields_mirror_between_schema_and_model` против подсунутых мутированных схем:

```
список исключений: {'skill_spec': {'assets'}}

0. схема как есть в ветке          skill_spec -> PASS ; rule_set -> PASS
1. в схему добавлено поле, которого нет в модели
                                   skill_spec -> FAIL: «схема разрешает поля, которых нет в модели — ['bogus_field']»
2. из схемы rule_set убрано поле (kind без исключения)
                                   rule_set   -> FAIL: «в модели есть поля, которых нет в схеме и нет в _SCHEMA_DROPPED_LEGACY_FIELDS — ['scope_globs']»
3. assets вернули в схему          skill_spec -> PASS
```

Послабление действительно одностороннее и именное: опасная сторона («в схеме есть, в модели
нет») роняет тест по-прежнему, а «только в модели» разрешено лишь для явно перечисленного
поля явного kind'а — у `rule_set` то же самое падает. Список не wildcard, расширяется только
правкой теста руками. Третья ассерта (`legacy <= model_fields`) не даёт исключению пережить
поле.

Единственная мелочь (случай 3): если `assets` когда-нибудь вернут в схему, запись в списке
станет мёртвой и никакой тест об этом не скажет. Дыры это не создаёт — поле в таком случае
легально с обеих сторон. На гейт не влияет.

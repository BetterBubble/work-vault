# Что уже есть в двух заявляемых продуктах — инвентарь под заявку на льготу

Разведка read-only 06.08.2026 под заявку в ИНТЦ «Квантовая долина». Ничего не правил.
Задача: отделить **уже работающее** (нельзя заявлять как новую разработку — «потом выпотрошат»)
от **почти готового** (самое ценное) и от **пустых ниш**.

**Рамка продуктов (решение Завьялова Алексея):** (1) АВИС + Terra, (2) IVA Largo + голосовой
ассистент + AI + Terra. Из канона: **АВИС ≈ MCU** («коммерческий, равный MCU, но как продукт»,
правообладатель МТС + Масштаб), поэтому всё, что доказано по `ivcs-server`/MCU, — это и есть
функциональная база АВИС. Ключевая оговорка их же стороны: **что приобреталось в MCU и
не прилепилось к АВИСу — для АВИС новая фишка** (`canon-innovacionnye-fichi-lgota`, дословно).

## 1. Terra как ИИ-ядро — полный список возможностей и к чему подключено

**Главное:** Terra = **речь, а не генерация текста**. ASR + диаризация + машинный перевод + TTS +
**HTTP-шлюз к внешнему языковому модулю ADP**. Своей LLM у Terra нет; RAG и векторного поиска
текста нет (доказано счётчиками по `terra-core.xml`: qdrant/faiss/milvus/langchain/vllm = 0).

| Возможность Terra | Состояние | К чему подключено сегодня | Подтверждение |
|---|---|---|---|
| **ASR (`terradyne`)** — форк faster-whisper: CTranslate2 + Whisper + silero-vad + wav2vec-элайнер | **прод** | ВКС/MCU (`/process`), диск (`modules/diskstorage`, IVADS-229 с июня 2025) | `terra-core/rapi/terradyne/*`; recon-corpus §4 |
| **Диаризация** — вендоренный **WeSpeaker** (~70 файлов), спектральная/UMAP-кластеризация, PLDA, ONNX | **прод с 2026-02-17** | ВКС | `rapi/diarizator/*`; коммит `offline_worker: added speaker diarization` |
| **Машинный перевод** — **MarianMT** (Helsinki-NLP/opus-mt), веса в репо, детект языка на fasttext, 53 языка | **прод** | ВКС: субтитры на лету (`/translate_to_any`) и пакетный перевод стенограммы | `translator_service/*`; recon-vks №6, №7 |
| **TTS (`tts_service`)** — синтез речи, отдельный воркер | **есть с 2025-10-29, потребителя НЕТ** | **ни к чему в продуктах** | `terra-core/tts_service/code/*`; в контракте MCU три ручки — `/process`, `/minutes`, `/translate_to_any`, TTS среди них нет |
| **Постобработка `/minutes`** → три документа: полная стенограмма, **поручения**, **конспект** | **прод** | ВКС | `TerraTranscriptionType: FULL_TRANSCRIPTION / ASSIGNMENTS / SUMMARY` |
| **ADP API GATE** — шлюз к языковому модулю, SSE-стриминг | **реализован 05.12.2025** | Terra ↔ ADP | `IVATR-158`, `rapi/adp_processing.py` |
| **Белый список сервисов ADP** — `["assistant","summary","planner"]`, **настраиваемый параметр** | прод | — | `settings_holder/default_settings/adp_api_gate_related.py:181` |
| **API `/audio2text`** — одиночный аудиофайл до 500 МБ | **в разработке** | — | Jira `IVATR-150` |

### Языковой модуль ADP (`blank130/iva_adp`) — что реально умеет

Это **не Terra**, а отдельный сервис на vLLM 0.19, к которому Terra ходит. Проверено на живом сервере.

| Задача ADP | Состояние | К чему подключено |
|---|---|---|
| `summary` — конспект, карта-свёртка по фрагментам, XML-теги, мягкая деградация | **промышленно** | ВКС через Terra `/minutes` |
| `planner` / `planner_adv` — **поручения с ответственными и сроками** (`action_items`: `task_description`, `assignees`, `deadline`, нормализация дат, промпты по языкам) | **реализовано** | ВКС через Terra |
| `assistant` — диалог с **серверной памятью** (история в БД, до 20 сообщений, разделена по `cid`/`stype`) | **реализовано** | **ни к чему в продуктах** |
| `coder` — генерация с guided decoding | реализовано | ни к чему |
| `diar_identification` — сопоставление реплик именам спикеров, structured output | **реализовано с 02.2026** | только пилот `diarization_pipeline` |
| `summary_bot` — урезанный клон summary под бота | реализовано | ни к чему |
| OpenAI-совместимый API + стриминг + метрики vLLM + трассировка + таймауты | промышленно | — |
| **Rate limit / квоты** | **НЕТ ВООБЩЕ** | главный риск подключения новых потребителей |

**Железо:** Terra — 1× RTX 4090 или A16; **модуль ADP отдельно** — A100 80 ГБ / H100 80 ГБ либо
2× L40 48 ГБ. То есть конспект и поручения стоят отдельной видеокарты, а не «галочки».

**Bus factor:** Terra — 1 автор (Большунов Валерий, 0 MR за историю); `iva_adp` — 28 коммитов,
фактически 1 автор (Сакевич Елена). Владелец систем — sys-terra, Воронин Артём.

## 4. Что в прототипе / почти готово — самое ценное для заявки

| Что | Где живёт | Насколько готово | Что осталось |
|---|---|---|---|
| **Конспект + поручения на экране ВКС** | сервер уже раскладывает 3 файла, включается `EVENT_TRANSCRIPT_SUMMARY` | **сервер готов; ни один клиент настройку не читает** — слова «конспект» в UI нет ни на вебе, ни на десктопе (22 649 коммитов), ни на мобильном | карточка итогов встречи. Оценка 8–15 ч/д. **Но сначала проверка на стенде: развёрнут ли ADP** |
| **Опознание участников по голосу (`diar_identification`)** | ADP-задача с 02.2026 + пилот `blank130/diarization_pipeline` (5 коммитов) | задача в ADP реализована со structured output; в пилоте включается флагом `enable_identification=False` | вывести в продукт. **Ровно то, что просил их руководитель («подвесить фамилии над людьми») — но по голосу, а не по фото** |
| **Синхронный перевод речь-в-речь (S2S)** | `blank130/s2s_realtime_translator` | **прототип промышленного качества**: STT‖LLM‖TTS параллельно, WebSocket, свой фронт, две политики стриминга, измерения p50/p95, расчёт железа. Замеры: LLM 334 мс, STT 241 мс, **TTS 1.24 с = 65 % задержки**, общий бюджет ~1.9 с | продуктовая обвязка. **Прямо ложится на «перевод вытянуть на кодек» из их запроса** |
| **TTS в Terra** | `terra-core/tts_service` с 10.2025 | код есть, воркер есть | **потребителя нет ни одного** — готовый кирпич под голосового ассистента |
| **Демо «WAV → стенограмма + саммари + протокол»** | `diarization_pipeline/app/app_diarization.py` (Streamlit) | **рабочее демо для клиентов**, DOCX на выходе, саммари и протокол считаются параллельно | это витрина, не продукт |
| **Ассистент-диалог (`assistant` в ADP)** | ADP | серверная память диалога, OpenAI API, стриминг | нет ни одного продуктового потребителя. Подключение = новая задача в `app/tasks/` + строка в белом списке Terra |
| **Контур ассистента в прототипе One 1.5-RN** | ветка `rn`, вне основных веток | DeepSeek-шлюз (включён), **Qdrant + bge-m3 RAG (выключен)**, саммари письма + черновик задачи (E2E-тест), черновик ответа, «коммуникационная вики» (выключена), маркетплейс мини-приложений, BPM-движок | **генерация уходит в облако `deepseek.com`** — в таком виде показывать нельзя; замена на `triva` в контуре дешёвая. Владелец не установлен |
| **Наша собственная модель `triva`** | железо ИВА, `10.0.196.14:9034`, доступ через SSH-туннель | **жива, проверена вызовом**: Gemma-4 ~26B instruct, контекст 128K, OpenAI API за LiteLLM-роутером | стриминга нет |

### Что просили и у кого (27.07, лист подготовки к Шереметьеву)

Четыре пункта, `00-Board/prep-vstrecha-sheremetev-2026-07-27.md:109–123`:

1. **постоянный доступ на чтение для команды**, а не разовый токен под задачу — уровня,

   мобильный если появится;

   личная договорённость, и при отпуске или уходе человека канал исчезает»;
4. решение по мобильной библиотеке — от него зависит, возможны ли `figma_key` у мобильных

### Что известно про Variables API и премиум-гейты

- **Figma Variables API — 403 навсегда, scope Enterprise-only.** Поэтому цвета берутся
  token-join'ом через `design_get_tokens("iva-mobile")`, а не из Figma Variables.
  `90-Materials/kmp-role-handover.md:45–51`
- **Премиум-гейт `design_*`**: без подписки Tacticum сервер отдаёт 402 — это **другое** «платно»,
  не путать с планом Figma. Оба «платно» специально сведены рядом в квикстарте.

> вчера смог вытянуть данные о макетах. Просто выдал ему авторизацию в фигме.»

**Беспалов:** оплаченного аккаунта с Dev Mode нет ни одного (гипотеза), предлагает обход
`gethopp/figma-mcp-bridge`.

**Установлено разбором** `00-Board/razbor-figma-mcp-fadin-2026-07-31.md` (проверено по документации
Figma и живым `whoami`):

- локальный MCP-сервер — **только Dev или Full seat на платном плане**, на free его нет в принципе;
  «аккаунт с дев модом» ≠ **Dev seat**;
- удалённый сервер работает на free, но лимит **6 вызовов в МЕСЯЦ** на Starter при любом seat
  (Dev/Full на платном — 200/день); один разбор экрана съедает 2–4 вызова;
- **View-seat на платном плане проблему не решает** — те же 6 в месяц;
- второе условие, которое легко упустить: **аккаунт должен принадлежать тому же плану, что и файлы
  макетов** — иначе UI KIT не откроется ни при каком seat;
- `whoami` не расходует лимит — им можно проверить план и seat бесплатно;
- **пилот не блокируется**: по ADR-0061 токены берутся из каталога Tacticum, макеты в этом режиме
  идут скринами.

него жить, если это будет сложно решить» — то есть Figma-MCP не блокер.
`00-Board/brief-ds-figma-fadin-2026-07-31.md:114–121`

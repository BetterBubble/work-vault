## Следующий шаг — РАБОТА РАЗДЕЛЕНА НА ДВЕ, для двух лидов

Постановка: [[postanovka-dve-raboty-iva-write-2026-08-05]].
**Обоим перед стартом:** [[grabli-iva-write-na-chto-ne-nastupat-2026-08-05]].

**Работа 1 — отладка бота (`helm`).** Два дефекта видны в первом же ответе бота:
🔴 **не узнаёт человека** («вашу платформа мне не назвала» — `login` не прошёл
проверку, вместо факта общая справка) и текст противоречит себе («выдай ключ» +
«ключ отзывает администратор»). Дальше — сценарии и перевыпуск секрета вебхука.

**Работа 2 — лейн `iva-write-base` (`tacticum-dev`).** Вынести канал и тексты в один
лейн, подключать **ролям** одной строкой. **Эталон — работающая установка аналитика,
сверять составом с ней.** По ролям, не по профилям.

Работы независимы: разные репозитории, друг друга не блокируют. **Бот больше не
блокер раскатки** — Надежда прошла без него, ссылки выдал её агент.

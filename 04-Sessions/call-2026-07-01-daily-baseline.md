# Daily 2026-07-01 — baseline готов, LightRAG отложен

Транскрипт: [[call-2026-07-01-1029]] (memory://tacticum/00-inbox/call-2026-07-01-1029)

## Решения
- **Baseline принят «плюс-минус»**. Recall на семантике 0.97; по источникам: синтетические (наши) Recall 1.0, клиентские 0.94. Гибрид без реранкера себя не показывает — прирост даёт reranker. Мерить можно.
- **LightRAG сейчас не делаем — overkill**. Метрики уже хорошие, вопросы клиента фактологические (без сложных связей), граф не нужен. Делать только по запросу клиента и после его ответа; предварительно оценить трудоёмкость. → см. [[03-Decisions/lightrag-overkill-for-zus]]
- **Транскрибирование аудио — отложено**. План накидан, пока не реализуем.

2. Сделать документы, которые просил клиент, — в первую очередь, быстро; уточнить перечень и сроки.
3. Отдать сегодня доделанный baseline.

## Приоритеты
